## Publish with GitHub Pages
1. Create a new public GitHub repository (for example, `ambiance-links`).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish and copy the public URL (usually
   `https://YOUR-USERNAME.github.io/ambiance-links/`).
7. Open that URL on a phone and test both buttons.

The final QR code must be generated using the published GitHub Pages URL.
Do not print a QR code pointing to a local file or an unpublished preview.
